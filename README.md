# PD Team Builder

작업 하나와 역할 몇 개만 정하면, 바로 쓸 수 있는 에이전트 팀 프롬프트가 완성되는 미니 웹 도구입니다.
특정 프로젝트에 종속되지 않는 범용 도구로, 어떤 프로젝트에서든 반복해서 쓸 수 있습니다.

## 이게 왜 필요한가

AI에게 "이거 도와줘"라고만 하면 AI는 자기 나름의 일반적인 방식으로 답합니다.
그런데 실제로 매번 반복하는 작업에는 이미 나만의 순서, 나만의 체크포인트, 과거에 겪은 실수가 있습니다.
이 도구는 그걸 매번 새로 설명하지 않고, 한 번 잘 정리해두면 그대로 재사용할 수 있게 만드는 게 목적입니다.

## 두 가지 실행 모드

- **Claude Code 모드**: `CLAUDE.md`와 `.claude/agents/*.md` 서브에이전트 파일을 생성합니다. 실제 프로젝트 루트에 붙여넣으면 Claude Code가 역할별로 위임하며 작업합니다.
- **다른 AI 모드**: 채팅형 AI(ChatGPT 등)에 그대로 붙여넣을 수 있는 역할극 형태의 프롬프트 하나를 생성합니다.

## 빠른 시작 프리셋

버튼을 누르면 작업/역할이 자동으로 채워집니다. 순서는 실제 작업 흐름(리서치 → 요구사항 반영 → 화면 설계 → QA → 정리)을 따릅니다.

1. **리서치 synthesis** — 인터뷰/자료를 정리해 패턴과 인사이트를 뽑는 단계
2. **PM 요구사항 반영 (실전형 5역할)** — 이 도구의 핵심 프리셋. 아래에 별도로 설명합니다.
3. **화면 리뉴얼 기획** — IA/카피/QA 관점으로 실제 화면을 설계하는 단계
4. **디자인 QA** — 만든 화면을 디바이스별로 검증하는 단계
5. **케이스 스터디 정리** — 끝난 프로젝트를 포트폴리오용으로 정리하는 단계

### PM 요구사항 반영 (실전형 5역할) — 어떻게 만들어졌는가

이 프리셋은 일반적인 예시가 아니라, 실제 반복 작업(PM이 준 기획서를 받아서 화면을 찾고 UX로 풀어내는 일)을 인터뷰 방식으로 파고들어 설계했습니다. 그 과정에서 나온 핵심 원칙 두 가지:

1. **역할은 체크리스트가 아니라 실제로 결과물을 만들어야 한다.** "확인했나요?"라고 되묻는 대신, 그 역할이 할 법한 분석/아이디어/문서를 직접 초안으로 작성합니다.
2. **수렴이 필요한 일과 발산이 필요한 일은 다르게 설계해야 한다.** 문제 정의나 목표 설정처럼 하나로 모아야 하는 일은 역할 하나가 통합해서 처리하고, 아이디어처럼 다양성이 필요한 일은 서로 다른 배경을 가진 여러 페르소나가 독립적으로(서로 참고하지 않고) 각자 결과를 냅니다.

그래서 5개 역할은 이렇게 구성됩니다:

```
리서치-가설 (PM·데이터팀·리서처 관점 통합, 수렴형)
        ↓
페르소나A(시니어 PD) / 페르소나B(PO 출신 PD) / 페르소나C(컨셉 디자이너)
  → 동일 문제를 3명이 독립적으로 탐색 (발산형, 서로 절충하지 않음)
        ↓
목표-지표 (세 시안을 지표 기준으로 검토, 수렴형 — 서열화하지 않고 지표별로만 비교)
```

## 참고 링크 (선택 입력)

작업 중인 Figma 파일 링크 등을 넣으면 생성된 프롬프트의 "참고 자료"에 포함됩니다. 화면을 직접 만드는 역할이 있다면, 새 파일을 만들지 않고 그 링크의 파일 안에 새 페이지를 만들어 배치하도록 안내 문구가 자동으로 붙습니다.

## 실행

빌드 도구 없이 정적 파일로만 구성되어 있습니다.

```bash
npx serve .
# 또는
python3 -m http.server 8000
```

## 배포

Vercel에 그대로 올리면 됩니다 (Framework Preset: Other / 별도 빌드 설정 불필요). GitHub 저장소에 push하면 자동으로 재배포됩니다.

## 새 프리셋 추가하는 법

`script.js`의 `PRESETS` 객체에 항목을 하나 추가하고, `index.html`의 "빠른 시작" 영역에 같은 `data-preset` 값을 가진 버튼을 추가하면 됩니다.

```js
PRESETS["새-프리셋-키"] = {
  task: "이 작업을 한 줄로",
  roles: [
    { name: "역할 이름", desc: "여러 줄로 목표/관점/반드시 출력할 것/절대 하지 말 것을 적어도 됩니다" },
    // ...
  ]
};
```

`role.desc`는 여러 줄을 지원합니다 (textarea). CLAUDE.md의 요약 목록에는 desc의 첫 줄만 쓰이고, 전체 내용은 해당 서브에이전트 파일 본문에 그대로 들어갑니다.

## 구조

```
index.html   화면 마크업
style.css    스타일
script.js    입력값 → 프롬프트 생성 로직, 프리셋 데이터
```

## 참고

인터랙션 아이디어(작업+역할 입력 → 프롬프트 생성)는 [Systems by Chuck](https://she-ate-the-prompt.vercel.app/)의 "나만의 팀 만들기"를 참고했습니다. 다만 역할 구성 로직과 프리셋 콘텐츠는 실제 반복 업무를 인터뷰해서 새로 설계한 것입니다.
